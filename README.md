# 瞬息全宇宙：逃离贝果

<p align="center">
  <img src="assets/art/engine/opening.jpg" alt="瞬息全宇宙：逃离贝果开场画面" width="420">
</p>

一款以多元宇宙追逐为主题的竖屏像素风互动网页游戏。宇宙裂缝已被贝果怪物撕开——在不断重构的迷宫中收集碎片、降低坍塌值，并通过跃迁穿梭于四个风格迥异的宇宙，赶在坍塌彻底失控前逃出生天。

> 本项目是用于学习与创作的非官方互动游戏原型，与相关电影及其版权方无隶属或授权关系。

## 在线试玩

**[点击进入《瞬息全宇宙：逃离贝果》](https://celia099.github.io/Everything-Everywhere-All-at-Once/)**

建议使用较新版本的 Chrome、Safari 或 Edge，并开启声音以获得完整体验。页面采用 `9:16` 竖屏布局，手机端和桌面端均可游玩。

## 游戏目标

- 坍塌值会随时间持续上升，贝果怪物靠近时上升得更快。
- 收集散落在迷宫中的宇宙碎片可以降低坍塌值。
- 被贝果怪物碰到会立即增加坍塌值。
- 将坍塌值降至 `0%` 即可通关；达到 `100%` 则挑战失败。

游戏分为两个阶段：

1. **教学关**：进入石头宇宙，熟悉移动、收集碎片与躲避追逐者。
2. **正式关**：在石头、洗衣店、热狗与功夫宇宙之间随机跃迁。不同宇宙拥有不同的场景、角色表现和追逐压力，跃迁时迷宫也会重新生成。

## 操作方式

| 操作 | 手机 / 触控设备 | 桌面设备 |
| --- | --- | --- |
| 推进开场 | 点击画面 | 点击画面，或按 `Enter` / `Space` |
| 角色移动 | 在游戏画面中按住并拖动 | 使用鼠标按住并拖动 |
| 宇宙跃迁 | 点击右下角“跃迁”按钮 | 点击“跃迁”按钮，或按 `Space` |
| 音乐开关 | 点击右上角喇叭图标 | 点击右上角喇叭图标 |

> 跃迁技能在正式关开放。使用后可以降低坍塌值、切换宇宙并重置追逐者位置，但需要等待冷却结束才能再次使用。

## 项目特色

- **完整开场体验**：三段式像素叙事画面，无缝衔接教学关卡。
- **四种宇宙主题**：石头、洗衣店、热狗和功夫宇宙拥有独立的背景、角色与追逐参数。
- **动态迷宫**：采用单格宽道路与障碍的随机迷宫，每次宇宙跃迁都会重构路线。
- **实时坍塌系统**：时间、追逐距离、碰撞、碎片和跃迁共同影响坍塌值。
- **像素视觉系统**：界面、文字、按钮、进度条、角色和收集物保持统一的像素风格。
- **程序化背景音乐**：使用 Web Audio API 在浏览器内离线生成并循环播放 8-bit / synthwave 音乐。
- **零构建运行**：由原生 HTML、CSS、JavaScript 与 Canvas 构成，无需安装前端框架或打包工具。

## 本地运行

项目没有依赖安装和构建步骤。下载或克隆仓库后，在项目根目录启动任意静态文件服务器即可：

```bash
python3 -m http.server 8000
```

然后访问：

```text
http://localhost:8000/
```

也可以直接打开 `index.html`，但使用本地服务器可以避免部分浏览器对本地音频和资源加载的限制。
