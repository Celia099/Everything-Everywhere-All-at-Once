关卡数值机制（Play）

本页面用于记录 play.html 运行时的关卡数值与规则（迷宫、坍塌值、碎片、技能、贝果 AI）。 入口建议使用 play.html。

地图：9×16（单格通路） 第1关：tutorial 失败：坍塌值 ≥ 100

地图与空间

地图与操作手感绑定：尺寸、tile 大小、圆形碰撞半径不变。

逻辑分辨率
720 × 1280
迷宫网格
mapCols = 11，mapRows = 15，边框为墙（1），通路为 0。
通路宽度
单格通路，tileSize = 60（每格 60px）。
出生点（格）
玩家：(1,1)；贝果出生点（循环使用）：(9,1) (9,13) (1,13) (6,11)

角色与碰撞

角色为圆形碰撞体；所有墙体碰撞通过圆-方块推挤解决，保证不卡墙。

玩家
radius = 13，speed = 140
长按加速
全宇宙统一启用：短按/刚启动时灵敏度 60； 按住 0.3s 后开始线性加速； 0.8s 达到峰值灵敏度 80； 松开即刻恢复至 60。
贝果（追逐者）
radius = 12；速度/视野由宇宙参数决定（见下方）。
碎片
radius = 8

坍塌值系统

核心进度条：随时间上升，靠收集碎片/技能下降，触墙无额外惩罚，被贝果撞击会额外上升。

初始坍塌值
initialCollapse = 50
时间增长（分段）
第1关：+0.5%/秒（基础）； 第2关：0–30s +1.2%/秒，30s+ +2.0%/秒
靠近贝果加速
两段区域：外圈 150、内圈 90。 第1关为绝对增速（外圈 +0.8%/秒，内圈 +1.2%/秒）； 第2关为倍率（外圈 ×1.5，内圈 ×2.5）。
撞击惩罚
被贝果撞到一次：+12%，并将该贝果重置回对应出生点且立即静止。
胜负条件
胜利：collapse ≤ 0；失败：collapse ≥ 100。

碎片系统

碎片只能出现在通路格上；刷新会避开玩家与贝果附近区域，避免“刷脸”。

同时存在数量
最多同时 7 个
收集收益
第1关：每个 -8%；第2关：每个 -5%
复活时间
第1关：2.5s；第2关：2.0s；第2关当场上碎片 ≤ 3 时，会自动补到 5。
安全刷新距离
safeSpawnDistanceFromPlayer = 170（离玩家太近不刷；离贝果也会做近似约束）。
第1关目标
通关条件按当前实现为：将坍塌值降至 0%。

技能（跃迁）

技能用于“换宇宙 + 降坍塌”。教程关与正式关的技能效果不同。

冷却
第1关：无跃迁技能；第2关：13s
降坍塌
第2关：单次 -15%
正式关效果
随机切换宇宙（四宇宙池），且禁止连续切换到同一个宇宙。
教程关效果
技能会把宇宙稳定在石头宇宙，并重置追逐者位置。

贝果 AI（追逐/游走）

基于网格可走格与圆形碰撞：在视野内追逐玩家，否则随机游走到 walkableCells 的目标格。

决策频率
追逐：chaseDecisionInterval = 0.18s；游走：wanderDecisionInterval = 0.6s
卡住检测
stuckCheckInterval = 0.9s；若位移不足会重置游走目标。
方向可行性采样
路径可行性会做短距离探测（典型探测距离 28/32），确保不会卡墙。

宇宙参数（速度/视野/数量）

每次跃迁进入不同宇宙，会改变贝果数量、速度与视野。

石头宇宙（stone）
第1关：贝果数 1；速度 80px/s；视野 60px
第2关（简单模式）：贝果数 2；速度 70px/s；视野 60px
洗衣店宇宙（laundromat）
贝果数 3；速度 120px/s；视野 100px
热狗宇宙（hotdog）
贝果数 5；速度 80px/s；视野 100px
功夫宇宙（kungfu）
贝果数 3；速度 80px/s；视野 160px

第二关跃迁权重（随机池）

第2关跃迁使用基础权重抽取；抽取时会先排除“当前宇宙”，再对剩余权重做归一化。

基础权重（全局）
石头 20%；洗衣店 25%；热狗 25%；功夫 30%
第2关权重（抽取策略）
每次跃迁：排除当前宇宙后，对剩余宇宙按基础权重归一化抽取（总和为 100%）。
连续限制
跃迁禁止连续切换到同一个宇宙（抽取时排除当前宇宙）。
开局限制
第2关开局不会落在石头宇宙；开局会在洗衣店/热狗/功夫中按权重归一化抽取。

随机迷宫（四宇宙约束）

每次进入游戏、每次跃迁到新宇宙，会生成符合该宇宙风格的随机迷宫，并重算碎片刷新点。

  • 每次进入游戏（reset）生成新迷宫；每次切换宇宙（universe key 变化）生成新迷宫。
  • 迷宫边框固定为墙；玩家出生点与贝果出生点保证为通路。
  • 地形兜底：尽量消除全封闭死胡同与极端超长窄道，避免地形导致的难度异常。
  • 碎片刷新：热狗/功夫优先交汇处与开阔处；石头/洗衣店为普通随机。所有刷新点都在通路格上，且避开玩家初始位置附近。
